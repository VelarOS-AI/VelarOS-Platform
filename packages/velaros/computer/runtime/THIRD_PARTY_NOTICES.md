# Computer Use runtime dependencies

Computer Use loads these upstream libraries through their public Python APIs. Their original distribution metadata, copyright notices and licenses remain in the bundled Python installation (`site-packages/*dist-info/`, and `av.libs` where provided by the wheel).

| Dependency | Use | License / upstream |
| --- | --- | --- |
| PyAutoGUI 0.9.54 | Pointer, dragging and named key input | BSD-3-Clause, [PyAutoGUI](https://github.com/asweigart/pyautogui) |
| pywinauto 0.6.9 | Windows UI Automation and literal Unicode input | BSD-3-Clause, [pywinauto](https://github.com/pywinauto/pywinauto) |
| pywin32 | Windows horizontal wheel event (transitive dependency of pywinauto) | PSF, [pywin32](https://github.com/mhammond/pywin32) |
| PyAV 19.0.2 | Streaming MPEG-4 encoding and MP4 muxing | BSD-3-Clause, [PyAV](https://github.com/PyAV-Org/PyAV) |
| FFmpeg supplied with PyAV wheels | Native video codecs | License reported by the installed FFmpeg build (validated Windows wheel: LGPL-3.0-or-later); preserve the wheel's FFmpeg notices and source/build references. [PyAV wheel builds](https://github.com/PyAV-Org/pyav-ffmpeg) |
| Pillow 11.3.0 | Image conversion | HPND, [Pillow](https://github.com/python-pillow/Pillow) |
| MSS 9.0.2 | Screen region capture | MIT, [python-mss](https://github.com/BoboTiG/python-mss) |
| screeninfo 0.8.1 | Monitor identity and geometry | MIT, [screeninfo](https://github.com/rr-/screeninfo) |
| PyObjC 11.1 | macOS Quartz / Accessibility bindings | MIT, [PyObjC](https://github.com/ronaldoussoren/pyobjc) |
| python-xlib | X11 window metadata and focus (transitive dependency of PyAutoGUI) | LGPL-2.1-or-later, [python-xlib](https://github.com/python-xlib/python-xlib) |

The implementation uses FFmpeg's native MPEG-4 encoder and does not require an external FFmpeg executable or x264. Platform-specific dependency receipts are generated by Desktop's runtime builder.

The FFmpeg license texts are included as `FFMPEG-COPYING.LGPLv3` and `FFMPEG-COPYING.GPLv3`, copied verbatim from [FFmpeg n9.0.2](https://github.com/FFmpeg/FFmpeg/tree/n9.0.2). Corresponding FFmpeg source is available at that tag; the PyAV wheel's build recipe and dependency configuration are provided by [pyav-ffmpeg](https://github.com/PyAV-Org/pyav-ffmpeg). Keep these files with the distributed native libraries.

Design references: [Microsoft UFO](https://github.com/microsoft/UFO) (MIT) for accessibility-first window/control operations, and [Cua](https://github.com/trycua/cua) (MIT) for an explicit input/capture capability surface. No UFO or Cua implementation is vendored in this runtime. Exact research revisions and local reference checkout locations are recorded in Desktop's computer-use documentation.
