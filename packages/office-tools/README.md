# @velaros-ai/office-tools

[中文接口文档](./docs/api.zh-CN.md)

## Responsibility

`@velaros-ai/office-tools` owns agent-facing office output tools: Word, PowerPoint, Excel, LaTeX/PDF creation, PDF conversion, PDF editing, and document preview helpers.

## Public Imports

- `@velaros-ai/office-tools`
- `@velaros-ai/office-tools/cli`

## Boundary

This package must not own workspace authorization, product IPC, renderer UI,
or agent runtime execution. It receives workspace/system behavior through its
tool context and returns file outputs for the host to present.
`OfficeRuntimePlatform` is host-neutral and forward-compatible; public Office
contracts do not depend on the `NodeJS` ambient namespace or on System Tools.

## Example

```ts
import { officeTools, type OfficeToolContext } from '@velaros-ai/office-tools'

const tool = officeTools.create_word_document
const input = tool.schema.parse({
  outputPath: 'reports/summary.docx',
  title: 'Summary',
  blocks: [{ kind: 'paragraph', text: 'Generated by a host application.' }],
})
const output = await tool.execute(input, officeContext satisfies OfficeToolContext)
```
