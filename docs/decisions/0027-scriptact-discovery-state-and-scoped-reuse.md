# 0027: ScriptAct 能力发现、预算状态与按范围复用

- Status: accepted
- Date: 2026-10-02
- Owners: `@velaros-ai/script`、`@velaros-ai/context`、`@velaros-ai/agent`、`@velaros-ai/model`、`@velaros-ai/velaros`

## Context

能力目录中的操作名与实际 import 导出需要分别表达；逐次查询完整声明和模板会增加往返与输入成本。完整当前状态改善了可理解性，也可能重复交付长证据、读取目录与源码差量。稳定观察和局部修复后的核查存在重复执行。取消、迟到结果与模型窗口之外的核查探测可能让成本统计缺项。

## Decision

- 从正式 TS 声明生成真实值导出索引与正文 `contentRevision`；按多个导出读取声明时保留共同规则及完整类型闭包。指定导出的模板由调用方显式读取。常驻索引保留完整条目并受字符配额约束，省略数量和完整分页入口明确展示。
- 当前状态采用确定性软预算编译。用户约束、失败与未知效果、必需缺口、未完成证据及有序身份保持准确；长的可召回细节进入当前任务与授权水位绑定的不可变归档。字段补读支持 JSON Pointer；细节读取遵循当前授权，不生成执行输出正文交付证明。宿主 `stateDetails: 'full'` 支持同源对照。
- Project 提供显式选择的文件纯快照计划。每轮经过真实授权、Kernel 回执和完整收束核对，前后两次读取一致时建立当前捕获值。相同完整捕获值（含领域版本）只复用领域固定纯派生结果，原派生身份与本轮捕获身份分别记录。任务、授权重置、观察源、provider 及模块绑定共同界定阶段；clear、完成与重置退役，失败或未知覆盖丢弃成功基线。
- 系统面 `programs.publish/list/describe` 提供当前任务的命名程序目录。发布检查语法与真实导入依赖，源码不可变；同名更新按 `baseRevision` CAS。执行使用已有 `sourceRef/input/blobs` 链路，当前授权与真实效果由每次执行兑现。
- Context 允许领域验收器按检查声明完整依赖、产物集合、范围及核查器版本。完整成功且前后依赖稳定的检查可复用；当前适用性另行探测，历史报告保留原范围与时刻。兼容核查器继续整项执行。
- 核查摘要强制保留原结果计数与当前适用性计数；详情预算不足时仍能辨认历史和未知证明。宿主执行活动另有独立分页，取消后的真实 journal 收束可以在没有模型请求的会话中读取。
- 模型已取得的供应商终态用量在取消时仍保存；未取得的用量保持未知。核查记录 started、settled 与 late-result，费用按收费身份去重并区分实际收费和参考费用。核查总账独立于模型请求窗口，额外适用性探测也进入成本覆盖。

## Compatibility and migration

`modules.describe` 的单导出调用继续可用，新增 `exports` 合并查询及明确模板选项。公共模型操作仍由所属 TS 接口生成声明、效果、发现内容与模板。

当前状态裁剪只影响可召回细节的展示，原内部帧及已有正文证明保持自己的身份与覆盖语义。软预算超载明确表达，由实际请求编译器核对最终容量。

快照计划与按检查复用由调用方显式接入。同值复用证明当前捕获值一致，领域可靠变化代次有自己的可信 probe 合同。程序目录的名称与描述负责发现，源码引用和当前授权分别负责定位与执行。

## Validation

Runtime INV-79、80、81、82，Context INV-16 与 Script 声明切片、依赖闭包回归覆盖这些边界。各项机制成本包括归档、发布、真实读取、probe、失败与取消。端到端收益由冻结独立任务、重复配对与完整计量决定；方案见 [Platform 运行主链](../architecture/platform-runtime.md)。

## Consequences

默认发现和当前状态链路增加少量固定元数据、版本与归档成本。程序发布适用于逻辑稳定的重复工作；Project 快照每轮两次读取，持续变化或昂贵 IO 时可能增加耗时。检查复用的净收益取决于 probe 与实际核查的成本关系。这些代价必须与整题正确率、耗时和费用一起评价。
