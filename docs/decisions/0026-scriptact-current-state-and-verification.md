# 0026: ScriptAct 当前状态呈现、领域核查与可信观察复用

- Status: accepted
- Date: 2026-10-01
- Owners: `@velaros-ai/context`、`@velaros-ai/agent`、`@velaros-ai/velaros`

## Context

此前请求保留已发送帧并以列表补丁和字段变化压缩新帧。模型需要跨帧重建当前失败、作业和状态。稳定观察每轮重复采集；自动 done 的目标收尾发生在领域核查前，核查失败可能留下已结束的目标。领域模板也存在读取缺口后写入子集、丢失命令真实状态与报告生成后缺少实际产物核查的问题。

## Decision

- 当前帧列全状态与有序列表，未变原文仍由冻结历史和引用承载。驻留身份目录独立于本段改动的笔记卡；超限目录明确缺口并提供原有分页读取。
- 领域核查可提供有界范围、时间、逐项结果、证据引用与产物身份。报告持久归档，任务只保留 completionRef；readCompletion 支持回看具体报告。当前帧的核查摘要带任务、宿主对象和核查范围，表示该次核查的历史事实。
- 自动 done 先领域核查，再把当前目标、任务状态和成功报告同次 CAS 发布。核查失败保留报告与待修状态；取消或对象替换不发布旧成功。宿主对象校验由中立 completion commit 端口接入 Context。
- observe 缺省每轮采集。宿主可登记完整依赖覆盖的 probe 与权限/可见性 scope：只有源码、输入、覆盖范围、provider incarnation 与变化 token 均吻合的完整成功观察可复用。未知覆盖、失败、超时、过期、重启、附件缺失或显式 refresh 走采集路径；实际调用与复用记录分开计量。
- 高频组合先由领域模板承载。模板保留读取缺口、命令状态与产物核查范围，批量写入依据完整输入；生成声明与文档继续从 TS 操作接口派生。

## Compatibility and migration

当前状态取代新帧的列表补丁呈现；已冻结旧消息保持原字节。公共模型操作面沿用既有操作；observe 提交可附 refresh。领域报告和可信观察端口为宿主可选接入，既有核查器的 verified/reason 结果继续可用。无可信覆盖的观察维持原采集行为。

自动 done 的核查次序和持久发布是行为修正。目标 revision 与任务 revision 阻止并发替换继承旧证明。模型显式目标更新继续按该操作的独立语义执行。报告证明其声明的核查范围，产物再次变化后按原报告身份读取历史事实。

## Validation

Runtime INV-74、77、78、既有 INV-44/48，Context INV-15，以及领域模板验收测试覆盖当前状态、原文证明、可信观察失效、并发收尾和产物核查。完整实现、冻结基线和收益证据见 [实现与证据报告](../engineering/scriptact-optimization-implementation.md)。

## Consequences

最新帧的状态可独立判断；代价是重复小型元数据，仍需真实模型任务核对完整成本。完整依赖覆盖的观察可减少实际采集；host probe 的覆盖完整性仍由领域负责。领域核查增加可审查的交付事实，调用和核查成本计入整题测量。详细方案见 [优化设计](../engineering/scriptact-optimization-design.md)。
