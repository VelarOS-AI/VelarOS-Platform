# 脚本上下文与结果租约：实现与验证

2026-09-20，实际仓库 `<repository>`，分支 `main`。

## 已完成

正式 active 链路已接入两个外层入口：`script.observe` 维护每轮自动刷新的观察脚本，`script.execute` 明确执行一次。运行时使用现有 ScriptAct、QuickJS、Kernel、权限、SQLite 存储及 ProviderRequestCompiler。

结果默认保留 2 个成功业务回合，允许 1–32；`results.retain` 重设剩余租期，`results.read` 按引用召回。自动呈现与读取不续租，过期后移出自动上下文，持久回执仍可查。

源码变化与输出变化分别提供 diff；失败响应不推进租期或差异基线。超预算时先缩小摘录并重新编译；必要信息仍放不下时明确阻塞。未知操作状态不会随普通结果正文到期而消失。

观察中已知修改操作在 prepare/派发前被拦截；命令使用同一 Shell 能力的宿主受限路径，执行入口保留原能力与审批。运行时诊断独立于脚本 output，脚本捕获异常也不能隐藏拦截事实。

## 边界与后续验证

- macOS 进程约束不能保证拦截所有通过系统服务产生的外部影响；能力的 effect 声明和受限处理器属于可信宿主合同。
- 真实模型长任务的稳定性、输出质量及成本尚需 API 场景评估；AI SDK 当前验证的是实际编译与模拟传输。
- 其他操作系统的原生约束需要对应平台验证；本轮 6 项条件跳过已计入报告。
- 租期负责退出自动上下文，持久结果没有按租期进行物理清理。ScriptAct 上游已经标明裁剪的输出，不能靠结果 ref 还原裁掉的数据。
