# 子会话宿主上下文装配差量

## 原因与边界

静态 AgentProfile 无法在派发时按真实任务读取业务主体记忆、选择独立浏览器或建立工作环境。装配属于宿主，运行时只负责调用、传递与生命周期。

## 公开合同

`VelarosAgentsOptions.prepareSession` 接收实际 job、派发输入和活动取消信号，返回 `AgentSessionContext`。返回值可替换本分支的指令、Node 工作环境与逐帧环境信息，并提供关闭函数。类型从现有运行时入口公开，不增加包子路径。档案、模块权限与子任务协议保持原合同。

准备结果仅用于本次打开的子会话；在关闭、建立失败或准备后取消时回收。准备函数失败前未返回的资源仍由宿主持有和清理。

## 验证

真实父子任务测试覆盖独立指令、环境路由、不继承父任务人员说明、结束释放，以及准备期间取消后不调用子模型并释放已返回资源。运行时子任务文件的 26 项测试、Velaros 包构建、全仓模块所有权检查，以及本批 4 个文件的有界 ESLint 检查均通过。
