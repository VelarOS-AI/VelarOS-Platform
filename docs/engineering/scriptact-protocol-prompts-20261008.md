# ScriptAct 两种传输的模型提示分流

日期：2026-10-08。

原生 JSON 工具和文本控制段分别提供调用说明，共同运行语义由同一入口维护。模型看到的稳定说明、当前帧协议与工具定义跟随会话实际选择的传输，并使用当前许可和宿主配置的名称。

## 差量与影响

| 范围 | 当前行为 | 理由与影响 |
| --- | --- | --- |
| 共同语义 | 整份响应接纳、调度、观察生命周期、原文绑定、引用编辑、完成核查统一说明 | 两种传输遵守相同运行边界 |
| 原生 JSON | 说明 `code/options`、JSON 字符串转义、同一响应多个工具调用、调用身份及回执 | 参数路径与实际工具 Schema 对齐 |
| 文本协议 | 说明控制头、裸源码与原文、闭合行、当前帧标记及头部选项 | 明确文本载荷的边界与编码 |
| 观察用法 | 完整源码登记或整体替换；分别给出编辑、刷新、退订写法 | 用户可持续维护当前观察，失败更新保留原版 |
| 工具许可与命名 | 固定说明、示例及原生工具名同步遵守 `allowed` 和 `names` | 受限会话得到与实际可用入口相符的提示 |
| 参数错误 | 共享编译器使用“源码”“选项”等通用术语，原生专用预算错误描述调用和 JSON 选项 | 修复请求采用当前传输可理解的描述 |

协议选项、公开 TypeScript 数据合同和运行语义延续既有定义；工具 Schema 仍从正式类型生成。README 与 INV-88 同步记录提示分流约定。实现位于 `native-protocol.ts`、`script-protocol.ts`、`NativeTurnDecoder.ts`、`RuntimeSession.ts` 与共享参数编译器 `script-records.ts`。

## 验证

- Velaros 包构建通过。
- `protocol-parity`、`text-runtime`、`text-decoder`、`host-instructions`、`node-runtime` 共 177 项测试通过。
- 新增请求级测试通过真实 Runtime 装配与测试模型驱动，核对两种传输的系统说明、动态提示、原生 Schema、自定义名称及完成路径。
- 从提示中提取的观察退订、编辑、刷新 JSON 示例通过真实原生解码器；错误参数仍拒绝接纳。现有真实 Node 用例覆盖观察更新、原文绑定、混合回执及协议切换。
- 提示长度维持原有测试上限。模块所有权、生成合同、错误构造、修改源码 ESLint、修改文件 Prettier 与差异空白检查通过。
