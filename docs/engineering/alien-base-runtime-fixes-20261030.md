# 异星基地运行问题与修复证据

本次调整四个内部实现，公开接口、操作声明、效果声明和模型模板不变。

- 日志结果：大请求正文先占完分页预算，导致脚本输出和调用结果预览为空。现在先分配执行结果与调用摘要，随后按剩余预算读取原始请求；总预算仍受限。`act/runtime/test/trace-index.test.mjs` 覆盖大请求、分页上限和完整正文读取。
- 浏览器尺寸：可见 Chrome 的实际内容区没有随截图视口调整，录像出现裁切或留白。外部 CDP 驱动使用 `Browser.setContentsSize` 调整内容区，再设置仿真视口；无可见窗口或不支持该命令时保留原仿真行为。嵌入式预览窗不走此分支。`browser-viewport-device-mode.test.mjs` 覆盖可见窗口、无窗口回退和原有移动模式。
- 上下文前缀：截图帧会清空此前接受的纯文本前缀。现在视觉帧继续复用已验证的文本基线，但不把图像持久追加到历史；历史改写、预算超限仍按原规则重建。INV-48 增加连续视觉帧回归，核对文本公共前缀和每轮仅有当前图片。供应商缓存命中率仍需同配置真实任务复测。
- 多余空白页：启动参数显式打开 `about:blank`，随后 `Target.createTarget` 又新建任务页。现在使用 `--no-startup-window`，页面只由会话创建。连接用户已有 Chrome 的行为不变，不删除其空白页。外部浏览器回归 14 项通过；真实 Chrome 首次打开 1 页、第二会话 2 页、关闭第一会话后 1 页，未出现多余空白页。

可见 Chrome 尺寸实测：1280×720、1440×900 两档移除设备仿真后，实际内容区仍与请求尺寸一致。

本机 Windows 的定向回归通过：上下文 INV-48 共 9 项、视口 5 项、日志 9 项。完整检查的构建、类型、格式和治理阶段通过；能力 Bun 用例 1219 通过、81 按平台跳过。其后的 Node 集成测试包含要求只读进程约束的用例，本机返回 `SHELL_CONFINEMENT_UNAVAILABLE`；三个等待该执行完成的测试进程未能退出，留存进程与日志后终止。没有降低进程隔离，也没有将这次完整检查记录为通过。正式发布继续依赖 Linux Actions 的完整质量门。

版本：Platform 0.6.83，Agent 9.9.3，Velaros 0.6.20。Desktop 的消费验证与真实任务重跑另行记录。
