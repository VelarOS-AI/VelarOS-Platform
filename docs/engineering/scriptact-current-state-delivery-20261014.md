## 当前实现

`ActContextPolicy.retainedFrameRatio` 为历史状态帧提供独立预算。计量采用同一驱动、当前正文、逻辑历史、不透明续接与容量校准；超额后重建权威当前投影，重新核对正文、引用和租约。计量与重建不派发模型，也不重复执行脚本或确认交付。`model-request.retention` 保留边界证据。默认值为 `1`：在总输入容量内沿用已接受前缀；`0` 逐轮重建，其他比例由宿主配置。

宿主 npm 安装可通过 `velaros:npm/<包名>` 显式导入，例如 `import {execa} from "velaros:npm/execa"`。工作区裸导入继续遵循 Node 的真实解析。首帧提供 `runtimeImport/fallbackVersion`，执行目录同时记录工作区实际身份与宿主安装的版本、清单和 README。作用域别名、exports 子路径、ESM/CJS 条件、Node 子进程和每次租约换版均已验证；未知包、越界路径和能力命名冲突拒绝。

Node 引子给出明确的宿主导入和文件编辑入口，正文长度与修复前基本持平；完整提示仍满足原有长度门禁。
