# ScriptAct 初始上下文与控制标记

日期：2026-10-03。范围：Desktop 系统空间首轮请求的只读拆分、Runtime 固定提示优化及帧标记的长度调整。核对现有 `hello` 请求，并用受控模型驱动读取实际 Runtime 请求；没有发起付费模型请求或恢复评测队列。

## 初始上下文

封存请求指纹 `83ef0a92fc914da7` 与调试面板一致。供应方报告输入 16,626 token、缓存读取 0、输出 34 token。当前驱动输入预算为 111,904 token，占用约 14.86%。发送前的 63,564 是 UTF-8 字节保守估算，后续由供应方实测校准，不能作为精确 token 数使用。

完整系统提示为 54,925 UTF-8 字节、35,237 UTF-16 字符，消息正文合计 6,999 UTF-8 字节。系统提示包含四个常驻模块：files、shell、interaction、widget；每个模块同时附带完整声明与示例模板。四份模板正文合计 14,190 UTF-8 字节，约占当前保守输入估算的 22.3%；这个比例不代表实际 token 节省比例。

固定开销的优化以完整操作合同为前提：完整声明仍常驻，示例按需读取；选定导出由正式声明切片并合并传递依赖。必要的授权、能力发现、来源、错误诊断和缓存断点保留。后续真实模型验证同时记录完成质量、端到端时间、实际输入与输出用量及费用，核对按需发现的往返是否抵消正文缩减。

## 控制标记合同差量

- Runtime 帧标记默认采用 8 位小写十六进制，如 `@@s1a2b3c4d`。默认完整标记从 35 个字符缩到 11 个字符。
- 每帧独立取得 128 位随机值，短前缀与本会话已分配的身份冲突时逐位延长。实际帧发送前在审计目录登记短标记，句柄重开只读对应元数据索引恢复集合，不读取历史模型请求正文；没有新增数据库列或存储 API。
- 主循环和整理候选验收共用实例方法生成标记，调节参数集中在 Runtime tuning；没有增加公共 API、模型操作或依赖。
- 整理候选验收只读正式状态，不追加身份审计，避免破坏候选发布的版本核对。实际帧登记失败会在模型请求发出前终止。
- 解码器保持当前标记的精确匹配和原有闭合规则。同帧修复保留身份，上一帧控制文本不能执行当前帧操作。
- 标记仍只进入动态帧尾，系统前缀和缓存断点位置不变；已封存追踪保留原文。
- Desktop 和 Harbor 测试从实际请求提取本帧标记。补充真实 Runtime 跨帧拒绝、持久会话重开后的强制碰撞、流式分片、前导零、自定义前缀和既有长标记的回归。

缩短长度已经由真实 Runtime 请求验证；对实际模型复制错误率、耗时与费用的影响需要后续实测。

## 固定上下文合同差量

- `residentModules` 默认提供正式声明，模型可首轮直接调用；示例经既有 `modules.describe({module, template:true})` 读取。授权、操作接口、参数上限与传递依赖保持完整。
- 常驻配置新增可选布尔值 `template`，显式 `true` 附带整模块示例，完整模块与选定导出均可使用。重复项的任一 `true` 启用一次，非法类型在激活前拒绝。Desktop 现有空间装配采用新的声明常驻默认值。
- 发现说明合并重复段落，指引只展示所需的 declarations 或 template；命令指引合并重复要求，并保留实际 shell/PATH、选项兼容、工具缺失、每阶段退出状态、stderr 分类与必要诊断。
- 示例正文与模块内容版本仍来自原生成合同；8 位控制标记、系统缓存前缀的分区方式及缓存断点位置沿用现有机制。

## 大小对照

按 UTF-8 正文计量，以下数值不含 JSON 封装和图片，也不作为精确 token 或扣费数据：

| 对照对象 | 优化前 | 优化后 | 减少 |
| --- | ---: | ---: | ---: |
| 相同四个模块配置的实际 Runtime 系统提示 | 51,216 字节 | 36,417 字节 | 14,799 字节 / 28.90% |
| 原 `hello` 封存请求的系统提示重建 | 54,925 字节 | 40,126 字节 | 14,799 字节 / 26.94% |
| 原请求重建后的系统与消息正文总量 | 61,924 字节 | 47,125 字节 | 14,799 字节 / 23.90% |

第一项在公开包构建前后捕获真实 Runtime 请求，四个模块的 declarations 与 template 原文逐字核对一致。第二、三项保持封存请求的 6,999 字节历史和当前帧正文不变，只替换本轮调整的固定段落。完整模板块（含代码围栏）贡献 14,298 字节，其余 501 字节来自重复指引精简。

实际供应方 token、端到端耗时、模型生成质量及总费用尚未在本轮真实付费调用中测量，不从字节比例推算这些指标。受控执行回归证明声明仍能直接调用、示例可完整召回和缓存前缀保持一致。

## 验证

公开包重建后，使用受控模型驱动验证实际 Runtime 请求和执行链：

- Runtime 完整测试 628 项通过；其中短标记与解码专项 63 项、常驻上下文专项 20 项均包含在完整测试内。
- Desktop 全部 199 个测试文件通过，包括独立 Electron 与 ASAR 中的 ScriptAct 执行回归；完整 `bun run check` 通过，四个类型分区顺序完成。
- Harbor 接入测试 15 项通过；本轮没有启动付费评测。
- Platform 的 `check:module-ownership`、lint、格式检查通过；两仓 `git diff --check` 通过。

Harbor 首次回归 14/15：受控模型仍用旧指引的固定句子判断可用性提示，断言异常使该测试运行返回 failed。更新为检查当前的未知工具探测与选项兼容要求后 15/15；实际 Shell、PATH、命令路径和可用性元数据核对保留。首次失败日志保留在 `/tmp/velaros-platform-compact-context-harbor-20261003.log`，通过日志为 `/tmp/velaros-platform-compact-context-harbor-recheck-20261003.log`。
