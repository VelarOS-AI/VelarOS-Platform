# 模块状态与输出边界差量（2026-11-09）

本轮接在 `c86aa8b7` 后，修复整模块静态排查发现的内部状态与输出边界。正式 `v0.7.3` 的两个 0.9.2 归档、源码身份及回执保持冻结，本轮不打包、不升级产品依赖。

| 模块 | 触发与结果 | 理由与影响 |
| --- | --- | --- |
| Agent | 不同父任务分配相同短子任务 ID 时，活动槽和故障账按完整子会话身份隔离；等待交互 ID 分配的旧请求不能进入下一次运行 | 保持公开 ID 和 API，仅修复内部所有权和取消边界 |
| Model | 静态目录、运行清单及派生配置返回独立数据快照；超大的单个思考分片也服从剩余字符预算 | 修改调用方拿到的快照不污染其他对象图；仍完整消费正文、用量及完成事件 |
| Script | 失败执行账保留每笔 `changeRef` 和文件列表，只合并没有改动引用的连续同类调用 | 复用已有 `foldCalls`，恢复撤回所需事实，现有条数与总输出预算不变 |
| Act agents/search | 保留合法 `__proto__` 表单键为自有属性；仅有候选摘要时也复核来源授权，撤权清空投影和自由历史 | 不改变表单形状；只有明确 `DENIED` 才按撤权处理，取消与后端原错继续传播 |
| Skills | 所有 owner 均失效时保留非 `PERMISSION` 原错；仍有合法 owner 时继续授权 | 共用宿主与 SDK 入口语义不变；README 示例在消费完环境后才释放租约 |
| Execution | PowerShell 脚本块不再被白名单判为只读或可并发 | 只改变保守分类，不执行测试字符串；普通 `where`/`where.exe` 查询仍可只读 |
| Office | Word 数字字号从磅换成 docx 半磅；识别出的序列化 sheets 若结构校验失败则在写前拒绝 | 修正单位与数据丢失；合法序列化表格仍保留实际单元格内容 |
| Computer | 拖拽与按住输入共用释放账本和租约，释放失败仍可重试；录像清理失败保留发布路径或原失败诊断 | 不新增 RPC 字段，未操作真实桌面或编解码器 |

## 合同与文档

没有新增或改变公开签名、模型操作、效果或生成声明。Agent README 原先描述整份请求和图片审计，与现行 v3 有界元数据归档不符，现按实现校正。INV-37 原先写“抢占旧响应”，与既有保留在途响应及已接受程序的实现和测试冲突，本轮更正承诺文字，运行协议和行为未改变。
