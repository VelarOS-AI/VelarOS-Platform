# ScriptAct 与 Codex 验收口径

当前验收顺序是稳定性、任务质量、端到端时间与完整费用。使用 gpt-5.6-sol/high、相同上游、任务、资源和合理一致配置，最多两个任务槽。当前已授权美元预算 unlimited；第三方实际费率未知，官方参考估算与实际扣费分列。开发题用于发现和修复通用问题，冻结独立集用于检验结论。

## “明显”的量化门槛建议

在读取独立集成绩之前登记以下建议，保留每个失败及未知状态：

| 优先级 | 建议门槛 | 当前证明范围 |
| --- | --- | --- |
| 稳定性 | 验收关键路径没有未解决的严重框架缺陷；独立集框架导致的挂起、身份或归账错误、未知效果重派、取消/清理失败次数不高于 Codex | 有离线与历史运行证据；Q 的输出分配、历史重置竞态与断点兼容修复已通过正式回归；独立集稳定性待验证 |
| 质量 | 冻结独立集总体官方成功率不低于 Codex；报告配对成功/失败矩阵及样本数 | 当前开发题跨候选，不构成新候选独立集总体成功率 |
| 端到端速度 | 双方都成功的配对中，每题端到端耗时比值的中位数不大于 0.80；同一配对子集的 ScriptAct P90 耗时不高于 Codex | T2 已结算且本题 ScriptAct 更慢；U 同题官方通过但自身耗时+4.56%，原路径未触发；整体优势待独立集 |
| 费用 | 前两项成立后降低费用；参考估算和实际扣费分别报告，缺失项保持未知 | 上游实际费率和历史中断的完整费用未知 |

门槛是待实测的验收建议。达到单题或开发题门槛只作诊断，整体领先须依赖冻结独立集。报告点估计、配对不确定性区间和实际样本数；样本或完整计量不足时明确无法证明，不追加题目直至显著。

## 核心优化的同题回归

每项核心性能修复分别验证机制与整题效果。先用真实 Runtime 链路复现缺陷，检查修复后对应路径以及授权、重置、正文退役、取消等负例；再保留旧候选成绩与冻结产物，在相同精确任务、模型、上游和资源下运行候选与 Codex。报告官方质量、解题时间、完整 attempt、完整参考费和实际费覆盖、上下文、缓存及分层工具数据。机制未在实测中触发时标记 `trigger_not_exercised`；同题单次更快仍不能单独证明因果收益。

代表任务的精确 ID、版本、配置及选择理由在运行前固定，后续持续复用；必要的重复运行用于估计模型与上游波动。跨题成绩用于开发诊断，版本提速由固定同题比较检查。当前首个连续版本回归为 T2→U 的 Element Web；已有异质零模型复现已通过；U在线未触发旧路径，ScriptAct参考费下降12.08%，自身耗时增加4.56%。

`version_regression.py --config <固定比较配置> --output <新输出>` 已实现同题版本比较。配置登记两份冻结清单、终态报告、已在清单固定的价格文件、参与方、独立对照方与任务 ID；运行只读数据，不派发模型。顶层及所选双方的实际模型与推理强度、上游、资源、任务/镜像/官方文件不一致或未结算时拒绝比较；控制组实现、配置及声明的二进制哈希与身份跨版本保持相同。兼容现有 bare/openai 模型名合同，比较配置在读取和完成时核对相同 SHA。失败任务的成功效率保持未知，未知费用不补零；分别保留 SDK 拒绝和网关失败。耗时上升、质量下降、必要计时缺失或出现模型失败会给出 `review_required`，单次观测不证明因果提速。

T2→U 的正式比较已输出 `version-regression-54u/result.json`，状态 `review_required`：ScriptAct自身解题和完整attempt耗时上升，参考模型费下降，同时模型中断已记录。当前比较工具的16项回归通过，模型、控制组版本和二进制哈希三个独立反例均拒绝；根 agent 实际 CLI 再计算的 `result-v3.json` 与原输出逐字相同。它补齐持续比较的工具入口，后续仍需按预先固定的代表任务收集版本结果。

## 计时与次数

端到端从该 attempt 的正式派发开始，到其官方重放、容器清理和归账确认结束；排队时间另列。解题时间使用 agent 实际执行边界，另列环境安装、模型、脚本、验证器、重放及清理时间。两个参与方使用同一口径。

执行记录保留全部实际尝试、中断、重试和恢复，用于身份、完整归账与故障审计。分别统计 Script 执行/失败、底层工具和模块调用、外层模型工具调用、Codex 原生命令及文件操作，以及各层时长与实际有效交付。单个脚本内部多次调用分别归账，用来定位重复工作和执行瓶颈。上下文峰值、总 token、缓存读写和命中率作为解释数据。

总体成功率包含全部计划中的 attempt，包括失败与超时；未知判分单独列出并同时提供保守下界。成功效率只比较双方都成功的配对，防止失败提前退出制造假加速。总体耗时及失败/未知的时间和费用另报，保留 P50/P90/最大值及原始记录。各候选和模型分别分组，不能把多个开发候选拼成一个新候选的成绩。
