# ScriptAct 核心与缓存断点联合优化

ScriptAct 的核心优化目标是稳定、正确地完成任务，并降低整题端到端耗时和完整费用。模型生成、脚本执行、结果交付、上下文维护和缓存断点共同构成执行链，优化优先级按实测贡献决定。双方继续使用 gpt-5.6-sol/high、相同上游和资源，开发题用于诊断，冻结独立集用于验收。

统一证据索引 `evidence_index.py`、自动诊断 `campaign_diagnostics.py`、控制器接入和 `repair_validation.py` 验证复用已经实现。70 项集成回归及 11 个分阶段独立反例通过；旧账本和候选保持。以下流程用于后续批次：

1. 统一批次产物索引，一次登记完整轨迹、原生会话、官方重放、请求账本和资源观察。使用正式读取器统一输出身份、时间、费用、上下文和工具分层；未知保留原因。源任务结束即生成基础诊断，重放和诊断可以并行，最终结算仍等待官方结果和迟到请求。
2. 将批次差异放入数据清单，复用已验证的采集、启动、结算和诊断代码。代码及依赖哈希决定证据可复用范围；每次仍执行实时身份、认证、容量、租约和账本门禁。避免每批复制一套仅批次名不同的 helper 再审查。
3. 主 agent 负责队列与集成，三个子 agent 按上下文/缓存、执行/工具、独立复现与回归分工。先用一份真实归档和异常边界确认公共合同，独审与修复同时开始；相关回归通过后统一封存一次。改变核心隔离、取消、预算、身份或缓存语义时运行对应完整门禁。通用反例覆盖多种数据形态，独立验证题继续隔离。
4. 记录环境、构建、回归、独审、排队、源执行、官方重放、诊断和集成的阶段时长。流程目标暂定资料齐全后基础诊断 2 分钟内、普通小修定位至集成 15 分钟内；这是待验证的周转目标，复杂核心修复按验收需要安排。


批次证据通过正式读取器恢复，源终态即可取证并与官方重放重叠。控制器终态刷新后发布独立不可变版本；活跃文件、缺失、身份冲突和异常均显式记录。诊断有独立 PID、120 秒期限及 5 秒收口窗口，取消时不延误源任务清理。复用同时核对全部输入、报告实现依赖及输出 SHA。

## 核心链路的修复

| 核心环节 | 根因与当前处理 | 验证边界 |
| --- | --- | --- |
| 增量上下文 | 数组只给 changed/total 无法准确恢复删除、顺序和重复项。改用位置、删除数量和替换片段；笔记与结果目录恢复当前完整顺序。 | 正式回归及 1,600 个变体重建通过；没有按评测仓库定制。 |
| 有效材料交付 | 均分额度使短结果留下空闲份额，长页仍只交引用。按实际编码需求分配同一结果池，短结果剩余份额供本批显式请求使用。 | 三页补读在原总额度内完整交付；整体默认预算保持，整题收益待实测。 |
| 历史正文复用 | 投影中途发生真实 history reset，先前 carrier 消失后仍可能隐去正文。核对最终实际历史载体，失效时进行一次有界本地重投影。 | required/optional、截断表示、重置和身份回归通过；仅实际交付证明能解除完整材料缺口。 |
| 缓存断点 | 内容相同的消息被误当成同一落点，原生点数与用户点可能冲突。按消息发生位置映射，保留调用方原生点，核对槽位与 TTL 顺序，派发前拒绝无效组合。 | OpenAI/Anthropic 实际 SDK 零模型出线验证通过；当前第三方显式 OpenAI 能力为 false，逻辑断点和稳定接受前缀继续保留。 |
| 脚本生成与复用 | 历史轨迹存在反复生成包装和参数化读取逻辑。指导使用已有模块、简短程序，并在更简单时以 sourceRef/input/精确 edits 复用已保存程序。 | 既有输入替换、底稿身份、增量编辑和真实副作用合同通过；不自动把相似脚本去重执行。 |
| Shell 生成与判断 | 管道最终进程成功时，上游检索仍可能因参数不兼容而失败，错误正文又挤占交付材料。R 在有 Shell 能力的指导中要求保留关键步骤状态、检查诊断，并按实际 Shell 与命令合同判断结果。 | 40 项相关回归、32 组能力配置及 4 个真实 Runtime 的零模型 SDK 会话通过；正常进度 stderr 保持成功语义，整题收益待实测。 |
| 评测比较 | 新报告按官方质量、完整 attempt 耗时、完整费用比较；agent 时间与 token/缓存/工具数据解释瓶颈。 | 原始派发身份与次数用于归账、恢复和故障审计；未知费用保持未知，成功效率只比较双方正常成功的配对。 |

缓存链落点包括稳定说明、段底座、已接受帧和稳定结果边界。保留前缀必须以权限、来源和实际交付身份为基础；合法重置、折叠或改写重新建立前缀。缓存读取、写入、上下文增长和维护费用共同纳入整题账，缓存命中率本身不能决定优化是否成立。
