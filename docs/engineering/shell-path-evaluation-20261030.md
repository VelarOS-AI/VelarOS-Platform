# 长任务日志审计：Shell 路径探测

2026-10-30 的真实 Desktop 执行日志中，`frameEnvironment → getShellPath → resolve` 每轮重新遍历 Windows PATH，并为正常不存在的 Shell 候选记录 ENOENT 完整栈。此时环境加载已保留通过自检的 Shell，却没有用于同步默认路径读取。

本次修改沿用当前环境代次的已自检路径；显式传入环境仍重新解析，刷新清空旧缓存，关闭后仍拒绝调用。普通缺失文件使用不抛异常的 stat 查询，权限等其他错误继续保留日志。未改变 Shell 优先级、执行权限、资源限制、模型合同或公开接口。

回归覆盖默认重复读取不重新扫描、显式环境独立解析、刷新换代、关闭后拒绝，以及原有环境并发和取消测试。该修改针对已确认的重复扫描与日志放大，不声称证明或解决历史上所有 Node 环境准备超时。

真实任务按冻结的 Desktop / Platform 版本运行；不会在进行中的试验里替换依赖。新版本另行消费并验证。
