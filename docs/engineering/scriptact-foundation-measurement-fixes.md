# ScriptAct 根基修复：请求归属与测量合同

日期：2026-09-30。对应 F11、F12、F13。测试均使用离线夹具或本地 HTTP 假服务，历史轨迹仅作重新解析。

## 请求费用归属

控制器为每次尝试签发 HMAC 凭据，绑定 campaign、candidate、participant、task、attempt、job、phase。网关验证凭据后生成自己的 request ID，费用账本保存公开身份和请求事实；凭据和供应商密钥不进入报告。容器和原生 Agent 进程只获得对应尝试的凭据，控制器密钥保留在宿主。请求正文的 metadata 不能改变归属。

repository 启动器继续使用冻结的一次任务尝试；通用启动器把多任务、多次尝试拆为每个进程一个任务、一份凭据，`--job-name` 对应一个任务和一次尝试，具体 ID 决定实际归属。原生 Codex、ScriptAct 和其他适配器使用相同控制器协议。Anthropic 协议桥把已经验证的尝试凭据原样交给网关，不用控制器凭据替换它。

新网关默认要求签名尝试身份。install/replay 的模型派发在供应商请求前拒绝并记录，作用域 health 返回对应尝试的用量和拒绝次数。新报告按身份取得请求，因此任务阶段结束后的迟到结算仍归属于原尝试。重复请求 ID、同一任务 job 的多身份、身份清单缺失或冲突都使归属校验失败。旧记录仅保留可验证的串行时间窗核算；并发、相交时间窗或同一请求被多个任务重复认领时拒绝给出可比较成本。

迁移方式：下一轮创建新的冻结清单，纳入更新后的启动器、凭据和网关源文件哈希，启动新网关后再派发。历史账本与原始任务结果保持原有内容。控制器调度并发与供应商网关排队策略仍是独立配置；本次修复建立归属基础，不通过改变请求重叠方式宣称加速。

## 工具模块统计

每次尝试新增 `agent_metrics.tool_usage`，包括模块、操作、调用次数、状态分布、是否真实进入 Kernel handler、耗时分布、未知证据数量、逐次关联 ID。同一个调用在多个 trace 页面出现时去重，session/调用 ID 一起决定身份，终态不会被旧 pending 快照覆盖；冲突终态明确失败。

- ScriptAct 底层调用按 Kernel invocation 统计；Kernel lifecycle 的 startedAt 表示进入能力适配器，可能包含 effect gate 等待。
- 脚本执行次数和模型请求次数保留各自原有统计，不能与底层调用直接相加。
- ATIF 按外层模型工具调用统计；没有成功证据时状态为未知。
- Codex 原生事件另列命令、文件操作、MCP、网页搜索和协作操作；原生条目按线程和 item ID 去重。
- 模块发现计入实际 `velaros:modules` 操作，不能当成已经调用被发现的目标模块。
- 模块/操作汇总包含任务覆盖数。统计不保存输入、输出、命令正文或凭据。

旧轨迹没有真实生命周期时间戳时，相应开始状态与耗时保持未知。重试只有明确的 retryOf 证据才计入；相同参数的多次调用不能自动断言为重试。费用属于模型请求，不为每个工具虚构分摊。历史真实轨迹解析样例保存在 `.velaros-workspace/bench/foundation-fixes-53/historical-tool-usage.json`。

## 模型窗口与费用

窗口解析继续优先使用显式运行时元数据和当前鉴权作用域动态目录；静态回退按已登记 provider 和具体模型查表。未知家族前缀、私有别名和任意后缀不能获得凭名称猜出的巨大窗口，未知值交由上层保守处理。

`ModelPricingRates` 包含缓存读和写单价，普通输入、缓存读、缓存写、输出分别计算。`cost` 仅在完整计费信息可计算时给出；`knownCost` 保留已知分项小计，`costCoverage` 与 `unknownCostRuns` 显式指出完整性。缓存分项缺失与真实零通过 `tokenCoverage` 区分；已知缓存读不会因缓存写未知而从已知小计丢失。无效缓存总量不生成完整账单。旧持久账本缺少完整性证据时按部分估计恢复，不升级为完整费用。

合同影响：新字段是增量字段；`cost` 的语义收紧为完整估计，存在未知调用的合计返回 null。消费方应显示已知小计及未知状态，不将 null 转成完整零费用。当前统计金额仍是按配置单价的估计，实际供应商账单保留独立权威。

## 验证

离线检查覆盖跨 Python/JavaScript 签名一致性、篡改、正文冒充、阶段禁派发、两次同时段尝试独立归属、迟到请求、未知归属拒绝、跨会话工具 ID、旧 pending 重复页、真实/未知生命周期、敏感正文排除、缓存独立计费、费用部分未知与未知模型窗口。协议桥用本地 HTTP 服务验证签名凭据没有被替换。整体集成结果见 `scriptact-foundation-fixes.md`。
