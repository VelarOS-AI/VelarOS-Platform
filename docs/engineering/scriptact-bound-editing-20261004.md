# ScriptAct 版本绑定编辑：实现与验证差量

日期：2026-10-04。目标是在连续源码上定位并复用明确目标，减轻大量编辑时的坐标计算、原文复制、重复规划和失败重发。质量、端到端时间和完整费用是验收指标。

## 实现

`velaros:project.select` 按函数、类、方法等完整声明名定位，或在文件/已有目标范围内定位精确字面片段。JS/TS/JSX/TSX 和 Python/pyi 使用已有解析器；返回连续原文、首行位置及工具签发的 `target`。结构解析有错误时返回缺口，文本目标可用于修复。重复声明、重载和重复文本提供完整候选及必要上下文，由调用方明确选择。

`read` 与 `search` 的每个连续可编辑窗口也附带目标。每个目标绑定会话、项目、原始文件版本及实际展示范围；客户端提供的路径说明不能改变位置。工具计算 UTF-16 坐标并核对 Unicode/CRLF 边界。内部保留完整 SHA256，模型可见的 `target:`、`plan:`、`change:` 引用各为八位十六进制；同一脚本直接传对象。

`patch` 将同文件的所有目标一次拼接在同一原始坐标上，每个文件一个补丁，整批复用已有事务内核。权限、版本、覆盖、重叠与提交校验均须通过；其他区域被外部修改也拒绝陈旧目标。同点插入按输入顺序，编码、BOM、物理换行与目标之外的正文保持。

一个调用最多定位/编辑一千个目标；定位最多一百个源码文件，完整源码与返回正文各最多两千万字符，一项歧义最多二十个完整候选。事务文件规模沿用项目策略。原文和坐标按文件版本在当前调用内复用，每个目标只保存自己的选区覆盖。

正常提交默认返回摘要，完整差量保存在事务记录，可通过 `inspect(changeRef)` 获取，`undo` 整次撤销。完整回执用 `receipt:'full'`。明确未写入时返回 `blocked`、原下标的问题列表及 `planRef`；`amendments` 只修正问题项，其他正确步骤留在计划内，重新验证整个批次。取消和状态不明继续传播真实错误。

标准项目装配将领域回调接入 Kernel 效果记录：被拒绝和无变化为 `none`，实际写入为 `committed`。领域返回数据不作为公共模块的效果证明。评测统计另计 patch 的语义拒绝，保留传输成功、脚本成功和领域拒绝的区别。

```js
import { output } from 'velaros'
import { select, patch } from 'velaros:project'

const found = await select({ targets: [{ path: 'src/cache.py', symbol: 'Cache.load' }] })
if (found.issues?.length) {
  output(found)
} else {
  output(await patch({ edits: [{
    target: found.targets[0].target,
    text: '    def load(self, key):\n        return self.items.get(key)',
  }] }))
}
```

小片段使用 `within` + `match`；多文件重复规则在 ScriptAct 程序内从确定的读取目标计算新正文，再一次 `patch`。新建、路径移动和文件删除继续通过现有 `edit`。

## 实际轨迹暴露的分页长度问题与修复

Django 轨迹中，投影把实现正文的 JSON 编码大小 24,676 字符展示成分页终点，实际字段读取返回 23,953 个 UTF-16 字符；测试正文的对应大小为 34,496 / 33,652。模型读到真实末尾仍继续，抛出空页错误，随后又读取一个嵌套页包装。错误来自通用投影大小口径，修复不依赖该题答案或测试名称。

Script 展示目录的 `totalChars`、嵌套字段引用的 `chars` 与 Runtime 字段引用现在与选中 JSON Pointer 的实际召回正文一致：字符串按解码后的 UTF-16 长度，其余值按紧凑 JSON。根归档大小、采集 JSON 计量、内容指纹、原始正文、展示预算及 required 覆盖校验保留；续读指引明确使用每页返回的 `offset + text.length` 和 `totalChars`。

修复前的定向用例复现长度错误；修复后 Script **166 项**、Runtime **209 项**通过，覆盖空字符串、引号/反斜杠/制表符/CRLF、Unicode、嵌套字段、JSON 值及根归档。实际 Django 捕获正文通过新投影与正式字段读取器零模型重放，分别 2 页 / 3 页完整恢复，没有空页。该证明核对故障条件已经消除，不估算整题时间或费用收益。产物更新到实际 Desktop 后核对 Hook、加载快照与完全访问配置；证据为 `pointer-size-stability-20261004/`，真实源任务没有重发。下一候选继续使用真实开发题验证质量、速度和完整费用。
