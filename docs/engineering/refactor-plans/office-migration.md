# `@velaros-ai/office` 1.1.11 → 2.0.0 迁移表

这是一次**破坏性**发布：6 个入口收成 3 个，11 个名字从对外面上消失，宿主端口去掉一个方法，
十个工具的模型面去掉 `cwd`。本文件按符号逐条给出去向，并标出每一条在 Platform 仓内与产品仓
（Desktop、Workbench、Termel、Extension）里的消费点数量。

- 仓内消费点**本轮已全部改完**。
- 产品仓的调用点**本轮不改**，只列进第 5 节，由各产品仓自己按这张表改。
- 判断口径：消费点 = 直接 `import … from '@velaros-ai/office*'` 的源文件数（注释与文档不计）。

改造方案见 `office.md`（§2 目标布局、§3.4 要删的导出与替代、§4 工具面）；裁决见
`../foundation-pending-decisions.md` 第五节 C1–C4；仓库标准见
`../../architecture/module-ownership.md`。
