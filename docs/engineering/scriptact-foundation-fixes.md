## 根基合同

1. **语言行为由语言运行器负责。** Script 使用原生 ESM 链接与求值；对已复现的 QuickJS namespace 重导出缺陷，仅按 AST 转为独立内部桥模块与原生重导出，保留用户词法作用域、绑定身份和实时性。能力模块只暴露授权 RPC。
2. **真实执行事实高于调用方等待状态。** 取消或超时不能推导外部效果为 none，也不能提前释放真实写锁与持久化资源。
3. **领域负责提交，宿主负责权限，Kernel 负责调用身份。** 句柄不是授权；当前授权和版本在实际提交前验证。
4. **历史原文与当前解释分离。** 当前投影携带来源并允许纠正；原文保持独立权威。摘录与模型摘要明确标记，不能充当全文授权证据。
5. **测量不足保留未知。** 费用和工具次数按明确身份与记录层级统计，不能用时间相交、缓存缺席或会话结束猜测归属与成功。

## 适用边界

- 现有 QuickJS 对只含 CR、U+2028 或 U+2029 换行的异常栈行号存在偏差；原文直接执行也可复现。本轮 LF / CRLF 定位验收通过，该低优先级诊断限制保留为已知边界。
- 宿主进程内永不合作的 Promise 不能被 JavaScript 物理终止。关闭有界报告 pending，真实资源持续保留；需要强制回收的适配器由宿主提供可终止的隔离执行单元。
- 文件和沙箱使用提交前版本复查与进程内写门；操作系统没有跨文件原子事务，也没有通用 compare-and-rename。恶意并发写入的最终极短窗口需要 OS 隔离或独占目录，不以路径检查代替它。
- 当前意图仍包含模型解释；逐字证据验证来源和可见性，不能证明自然语言推理永不出错。最新用户原文、来源和历史均可核对。
- Windows 专用的原生进程与 Git Bash 测试在 macOS 按条件跳过；真实 Electron/CDP 与完整 Desktop 产品集成需要对应宿主验收。本轮公共消费面由独立打包合同检查覆盖。
- 旧轨迹缺少生命周期或完整成本证据的字段保持未知。新的冻结评测批次使用更新后的完整合同；本轮验证支持框架机制修复，不构成超过 Codex 的成绩证据。
