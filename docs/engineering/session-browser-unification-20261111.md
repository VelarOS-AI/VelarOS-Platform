# 会话协作与交互浏览器合同收敛

本次随基础包与能力包 0.11.0 发布，根发布标签为 v0.7.11。

会话协作只寻址宿主已存在的真实会话。`SessionPeer` 删除 `workspace`、`root`、`site`，保留身份、标题、运行状态及自身标记。`ask` 必须提供 `to` 与 `task`，不再声明宿主从未实现的三类工作区创建路径；对应枚举、错误码、输入分支与示例一起删除。项目及浏览器资源由各自能力提供，不由会话组织字段推断。`list`、`ask`、`tell` 的实际投递和取消语义保持。

模型声明由会话操作接口生成，模板、README、不变量与验收同步更新。验收中的工作区创建承诺改为真实已有会话的寻址与投递；不是缺省填入某一旧类型。Desktop 调用方须直接更新，无旧字段读取或兼容别名。

浏览器截图定格按受控页面的实际可见状态选择。可见 WebContentsView 与既有网页采用相同捕获流程，隐藏页面不请求界面定格；浏览器资源装配与公开宿主接口不新增专有窗口类型。

验证包括会话声明生成、输入与取消、真实 Node 模板声明检查，以及可见原生页面截图定格与恢复。Linux CI 执行本机 Windows 按既有边界跳过的 POSIX Node 程序场景。发布流程继续验证两份正式归档的普通安装、单一基础实例、严格声明与实际能力运行。
