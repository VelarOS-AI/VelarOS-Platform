# 独立验收证据定位修复（2026-10-13）

证据发现组件对照的第一例在进入语义裁定之前失败。模型先把 lib、build、dist 三个目录列为文件；已有一次位置纠正把 build 改成不存在的 build/index.js，复核因此保持 unknown。原控制器依照事先冻结的规则停止后续用例，2 次真实模型请求，已知参考费用 $0.1115712、缺失 usage 0；不能把这个结果算成发现机制改善或退化。

根因是位置纠正只收到失败身份、已读身份与错误，缺少实际目录条目。此次增加可选的 CompletionArtifactSnapshot.locations，供宿主在读取缺口时返回真实的有界路径提示。Desktop 只列授权工作区内、失败路径附近的普通目录；最多 8 个目录、每目录 64 个观察条目、共 256 个条目、16384 字节，不递归，不跟随符号链接。读取前后核对根和全部父目录的代次及工作区绑定。Runtime 将提示交给现有一次位置纠正，也交给补充取证的后续轮次。

提示只帮助定位，不能作为文件正文、完成证据或新的用户要求。目录、缺失文件、权限失败和不完整快照仍然保持 unknown；选中的文件仍须完整 capture 并绑定版本。既有判据、原文锚点、读权限、纠正次数、600 秒复核预算保持不变。旧宿主可省略该字段。

组件对照还需重新冻结：同一候选与宿主、同一模型，仅切换 discoverEvidence。先前尝试与费用保留在同一项 80 参考美元研究上限中，不能重置预算。JSON5 是已暴露的诊断样本；原先冻结的另外三例仍须在派发前核对历史网关确无调用。实际模型有效性与全流程任务交付待后续结果确认。
