# 能力默认引用与安装合同

## 公开合同调整

`FeatureSelection` 只保存 `id` 与 `generation`，表示初始上下文引用，不携带 `grants`，也不裁剪工具调用范围。宿主将产品引用装配为底层 Skill 选择时，从当前安装清单解析完整贡献；底层 Skill 的清单核验、环境租约和安装代次保持不变。

`FeatureSummary` 删除 `enabled`，`generation` 仅表示实际安装版本；`FeatureDefinition` 删除 `implicit`。能力目录提供全部已安装能力，默认引用只用于预载和展示，未引用的能力仍可按需加载。安装、升级和卸载继续描述实际资源状态，取消与管理写入确认保持原有合同。

本次直接删除旧字段，不提供别名或兼容分支。消费方需要同步删除全局启停状态、启停派生代次、默认引用中的权限快照，以及按这两类字段过滤目录或加载的逻辑。产品自有 schema 与内置能力元数据应采用同一格式。

## 模型说明与资源

模型指南不再将默认引用描述为任务指令或自动调用权限。`instructions` 指向技术说明，`prompt` 是建议任务输入，不自动追加到当前执行目标。Codex 来源的调用策略不转换为运行权限；来源文件可由导入器按原资源保留。

浏览器与 JS/TS 内置能力元数据同步删除 `implicit`。模型面声明和派生 schema 通过正式 `features` 声明生成器更新，不手改生成物。

## 验收边界

INV-3 验证默认引用只影响目录中的选中标记，未引用能力仍能列出并加载；既有验收继续覆盖加载取消、安装与卸载在宿主确认之前没有副作用。宿主是否真正提供完整目录与安装映射，由所属产品的接缝测试核验。

## 发行版本

删除公开字段后基础包与能力包同步进入 0.10.0，发行标识为 v0.7.10，平台代仍为 0.7。该版本直接采用新的引用合同，不读取旧选择或补造旧字段；产品必须同步调整自己的持久化格式与装配逻辑。
