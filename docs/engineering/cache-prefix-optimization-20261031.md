# 缓存前缀优化与问题证据

## 变更

异星基地同题测试的主线在连续视觉调试时，已接受纯文本基线不再推进；当前仍有任务级展示租约的图片每轮移到新帧尾，导致上一轮完整请求无法继续成为前缀。新实现对当前投影授权的附件按数据、媒体类型、来源、标签及重复次数核对：仍有效的图片保留原消息位置，只追加新图片。图片释放、身份变化、逻辑历史改写或容量重建会放弃视觉前缀，并尝试纯文本基线；运行终止及会话关闭释放视觉缓冲。没有延长租约，没有删除当前有效图片。

只保留前缀会增加历史状态文字，因此同时减少重复状态：Node 结果卡完整展示对象相同时仅引用先前完整卡片；inventory、children、jobs、materialStatus 的完整展示目录相同时按字段说明复用。当前有序身份清单保留删除、重排和重复；租约、正文交付状态、范围及未知字段改变会重新交付。失败回执、缺口、目标与进展仍逐帧保留。原始帧、授权核对和正文交付证明没有缩减。

另修正两处缓存配置接线：官方 HTTPS 的 GPT-6 Astra 支持已有缓存断点；Velar Cloud 适配器遵循宿主明确设置的 `openaiExplicitCacheBreakpoints`。托管模型公共 ID 仍按不透明标识处理，不根据名称猜上游能力，不默认给所有线路发送新字段。Cloud 当前不转发顶层会话缓存键，此次没有添加该字段或改变云端部署。

以上为内部组帧及已有配置行为调整，没有新增公开操作、效果声明或模型工具参数。Agent INV-48 从“视觉帧只用文本基线”更新为“当前授权附件可保留且只出现一次”；Runtime INV-74 补充完整相同目录的引用规则。类型及公开导出不增加入口。

## 真实记录离线回放

输入为 `compare-alien-base-velaros-20261030` 主线程的 59 份已归档请求。分别经过 Desktop 0.2.16 所带 Agent 9.9.3 与本次 Agent，再经实际 Velar Dev Chat SDK 编码；发送函数被离线捕获替代，模型与原任务工具均未执行。两个分支使用同一逻辑事件、帧快照、附件和工具定义。测试输出预算为 100，容量估算固定，容量重建由独立回归核验；回放没有包含真实运行的正文交付协调器或模型决策反馈。

字符串指标是实际编码消息各字符串值的 UTF-8 字节合计，排除图片 base64，不是 token 数，也不是供应商 usage。可复用文字按历史请求写入的完整消息边界比对；这仅验证结构条件，不证明服务商缓存仍在、路由相同或一定命中。

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 完整保留上一请求的衔接次数 | 18 / 58 | 58 / 58 |
| 每轮图片数量与内容 | 与原记录相同 | 与原记录相同 |
| 当前帧文字累计字节 | 1,333,436 | 719,844 |
| 全部发送文字累计字节 | 24,741,396 | 30,079,045 |
| 符合先前隐式写入边界的可复用文字字节 | 10,561,199 | 28,991,765 |
| 未匹配上述边界的文字字节 | 14,180,197 | 1,087,280 |

当前帧文字减少 46.02%，未匹配上述边界的文字减少 92.33%；保留完整历史帧使总输入文字增加 21.57%。不能只报命中比例而忽略这一成本。后续线上验证应同时看实际未缓存输入 token、总输入、缓存读写量、首响应时间及组帧时间。未重新执行整场游戏，未声称线上命中率达到 96% 或获得相同额度的费用下降。

本地证据保存在 Desktop 的 `artifacts/evaluation/2026-10-31/cache-optimization/{before,after,summary}.json`；逐轮保留出线摘要哈希和计量，不公开真实请求正文、截图或账户材料。回放脚本在 Desktop 的忽略目录 `scratchpad/cache-replay.mjs`。
