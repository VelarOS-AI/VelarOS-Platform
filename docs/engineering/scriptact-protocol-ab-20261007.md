# ScriptAct 工具协议实现与实测（2026-10-07）

默认使用原生 JSON 工具（`tools`）。修复后冻结的四项任务各跑三轮，原生完成 10/12，文本完成 7/12；追加完整一轮同样是原生 3/4、文本 2/4。选择依据是本次端到端完成率。两种方式均可显式配置，不把单模型小样本结果推广为协议本身的普遍优势。

## 配置与执行语义

Platform 的公开配置是 `protocol.transport: 'tools' | 'text'`，省略时使用导出的 `DefaultScriptProtocolTransport`。Desktop 设置中「高级运行时 → 工具调用协议」提供自动、原生 JSON、自定义文本三项，持久化为 `system.advancedRuntime.toolProtocol`，下一次发送读取最新设置，已打开的工作区同样生效。

```ts
const runtime = await createRuntime({
  // 模型、工作区与 Node 宿主沿用应用配置
  protocol: { transport: 'tools' }, // 'text' 选择自定义文本协议
})
```

Desktop 中 `auto` 跟随 Platform 默认。默认选择遇到声明不支持原生工具的驱动时使用文本协议；显式传入 `tools` 而驱动不支持时返回可见错误。

| 能力 | 原生 JSON | 自定义文本 |
| --- | --- | --- |
| 一次性程序、Node/Execa/Shell | `exec({code, options})` | `execute(options)` 控制段 |
| 持续只读观察、刷新、清除、快照 | `observe({code, options})` | `observe(options)` 控制段 |
| 原文绑定 | `blobs({name, text})` | `blobs(name)` 原文段 |
| 参数、宿主输入、模块、源码引用与精确编辑 | 共用语义编译器 | 共用语义编译器 |
| 后台执行与结果保留 | `options.async / retain` | `async / retain` |
| 显式完成、完成依据、领域验收 | `done({message, completion})` | `done(completion)` 与答复 |

两种传输只负责解码，随后共用 `compileScriptRecords`、程序预检、执行器、观察器和完成验收。完整响应全部通过后才派发动作；混合调用的回执按实际执行身份配对。受限会话仍按 `allowed` 裁剪。执行进程已退出且完成回收的普通非零退出保留失败结果并继续独立程序；取消、超时、未知效果和宿主故障停止后续派发。

原生执行和观察使用各自从 TS 类型生成的参数 Schema。`async/retain` 属于执行，`snapshot/refresh/clear` 属于观察，模型看到的合同与共用校验器一致。

## 实测方法

- 使用用户已配置网关的 `gpt-5.6-sol`，推理级别 `high`，经产品正式 `createAiSdkModelDriver` 和 Responses 通道调用；真实 Node 进程、文件写入、Execa 和独立验收。
- 每种协议使用相同任务原文、初始文件、模型、授权与预算：上下文 128000、输入窗口 100000、输出 12000、最多 12 次请求、单次任务最多 300 秒。每次尝试有独立工作区与状态目录。按任务和轮次交替两种方式的先后顺序。
- 本次隔离比较基础协议，项目包、子任务、搜索、长期记忆和自动整理关闭。其能力兼容由运行时回归覆盖。本次任务是小型文件与代码工作，结果不能推广为所有模型、供应商或大型仓库的胜率。
- 事先保存任务、验收程序、顺序与评分政策。成功要求运行完成且产物通过独立断言，包括原文逐字一致、输入文件不变、脚本可重跑和明确要求的观察/后台操作。模型自述完成不算通过。
- 新任务的验收器在调用模型前通过独立正确产物和破坏产物自检。验收在产物副本上进行，原始模型产物保留。正确参考产物不进入模型工作区。
- 原始请求、供应商请求体、流式事件、Trace、工作区、错误、用量和每次成绩都保存在忽略目录 `.velaros-workspace/protocol-ab-20261007/`。请求体不记录鉴权头。汇总脚本在所有预定尝试齐全前不选胜者。

## 开发证据与独立验证

最初的冒烟和六项任务用于诊断。它们暴露了原生观察 Schema 广告了执行专用字段的问题，以及控制说明增加后原始输入被固定半额预算提前裁剪的问题。修复分别落在操作合同和通用材料分配逻辑；后者只在全部用户输入能完整放入总预算时完整交付，超额输入继续分页。这些任务作为开发证据保留，不用于证明修复后胜率。

早期配置迁移任务的验收包含题面没有明确要求的深层别名隔离，因此在该轮评分政策中对两种协议对称排除，原始成绩和费用记录保持完整。

修复后重新冻结了四项任务：

1. 修复区间合并，验证排序、负数、相接、包含、空区间与输入不变。
2. 为含空格、Unicode、空文件的资源生成并重跑字节数/SHA-256 清单。
3. 将含反斜线、反引号、美元插值、制表符和 Unicode 的原文逐字写入文件并往返 JSON。
4. 持续观察状态、后台只启动一次批处理、依据最终状态生成并读回摘要。

两轮独立验证共 16 次尝试：

| 总耗时 | 417.869 秒 | 396.312 秒 |
| 单次耗时中位数 | 49.905 秒 | 55.982 秒 |

原生有一次原文转义错误。文本有一次完成产物但未按要求使用后台执行；另两次失败同时包含协议修复与供应商 `terminated` 中断，缺少用量。它们不能全部归因于协议，也不能将其不完整费用视为完整总费用。

因此，在读取中断证据后、额外调用之前写入 `stability-plan.json`，对同一冻结任务集两种协议各完整补跑一轮，不按成败挑题或替换旧成绩。补跑先比较成功数，再比较完整参考费用、请求数、耗时。

## 费用口径

固定比较参考价为每百万输入 token $4、输出 $20、缓存读取 $0.4。它不是当前官方定价或网关实际账单。含缓存与不含缓存参考费用均保存在成绩中；任一请求缺少用量时，该组完整总费用标为未知，不用缓存命中率替代总费用，也不删除失败调用。

本次包括开发诊断在内共 50 次真实尝试、266 次模型请求，累计任务墙钟时间 3193.297 秒。已报告输入 token 2716401、输出 token 86104；部分请求缺少用量，因此全部工作的完整费用未知。修复后的三轮原生组用量完整，含缓存参考费用为 $1.498641、不计缓存折扣为 $3.371332；文本组无法计算完整费用。

## 复现

从已构建的 checkout 创建独立快照，然后使用新的输出目录运行。设置文件只需含宿主已有的 `chat.apiKey` 与 `chat.baseURL`。

```sh
node scripts/agent/freeze-standard-runtime.mjs . /absolute/path/to/runtime-snapshot
node scripts/agent/protocol-ab/check-cases.mjs
node scripts/agent/protocol-ab/run.mjs /absolute/path/to/runtime-snapshot /absolute/path/to/new-results /absolute/path/to/settings.json validation 2 gpt-5.6-sol scripts/agent/protocol-ab/validation-cases.mjs
node scripts/agent/protocol-ab/summarize.mjs /absolute/path/to/new-results
```
