# Excel 绘图工作簿的表格预览

真实办公任务生成的 openpyxl 工作簿使用默认 DrawingML 命名空间。ExcelJS 4.4.0 的绘图解析器只识别 `xdr:wsDr`，在汇合关系时读取未建立对象的 `anchors`，导致整个表格预览失败。仅设置 `ignoreNodes: ['drawing']` 不能避开 ZIP 中独立绘图部件的解析。

Office 的 Excel 预览原本只抽样单元格，不渲染图表或图片。本次在内存读取副本中排除绘图 XML，并跳过工作表的 drawing 引用；源文件不写回。`summary.drawings` 给出绘图部件数，含绘图时 HTML 提示未渲染图表与图片、公式采用保存结果。其余工作表、单元格、批注解析路径不变。

没有新增宿主权限、入参或操作，也没有改变完整排版及公式计算能力的承诺。公开结果已有数字摘要映射，新增计数不改变其类型。README 同步说明预览边界。

回归覆盖默认命名空间、绝对绘图关系、ExcelJS 原生图片、批注、已缓存和未缓存公式、工作表截取及输入文件逐字节不变。真实任务工作簿的 8 张表均可读取，包含 2 个绘图部件。完整发布检查由 Linux CI 执行；Windows 不放宽只读执行隔离来绕过运行时测试。
